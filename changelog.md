# Changelog

All notable changes to the DApp.meme platform will be documented in this file.

---

## v2.0.0 - 2026-05-19

### Highlights

- Introduced Mobius DApp Protocol (MDP)
- Established the foundation for deployable token-native DApps
- Added multi-chain deployment support across Ethereum, BSC, Base, and HyperEVM
- Expanded the platform architecture for future DApp templates including prediction markets, PvP games, lotteries, and more

### Protocol

- Introduced the Mobius economic loop:
  Token → Participation → Revenue → Reinvest
- Added decentralized ownership model for deployable DApps
- Added token trust badge system:
  Safe Token, Decentralized, Recommended, Four.meme, Stablecoin, Unverified

### MemeDice

- Upgraded MemeDice contract to v1.3.0
- Added batch betting support
- Added adjustable probability betting system
- Added vault-style liquidity pool architecture
- Added decentralized renounce-control mode
- Added full on-chain admin operation logging
- Added fairness verification system
- Added advanced deployment configuration system
- Added game logo upload support
- Added subdomain reservation and protection
- Added Four.meme token auto-detection on BSC
- Added optional website and Twitter links for deployed games

### Explorer

- Added deployed game explorer with search and filtering
- Added leaderboard system for creators, tokens, and games
- Added dedicated creator dashboard ("My Games")

### Faucet

- Added BSC test token faucet for gameplay and deployment testing

### Infrastructure

- Improved Oracle throughput and concurrent randomness processing
- Added multi-chain Oracle support
- Added full English and Chinese language support

## v1.0.0 - 2026-04-22

### Initial Release

- Released the first version of the DApp.meme launchpad
- Introduced MemeDice as the first deployable DApp template
- Enabled one-click deployment for token-native dice games
- Added decentralized randomness Oracle
- Added deployable on-chain liquidity pool system
- Added support for custom ERC-20 tokens
- Added creator-owned game management system
- Added subdomain-based game hosting
- Added global leaderboard system
- Added English and Chinese language support

### Supported Chains

- Ethereum
- BSC
- Base
- HyperEVM
